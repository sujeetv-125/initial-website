# Personal Portfolio - Sujeet Kumar

A modern, responsive personal portfolio website built with HTML, CSS, and Vanilla JavaScript.

## Features
- **Modern Design:** Clean aesthetic with a focus on typography and spacing.
- **Dark/Light Mode:** Toggle between themes with local storage persistence.
- **Responsive:** Fully optimized for mobile, tablet, and desktop.
- **Smooth Animations:** Reveal-on-scroll effects and smooth section transitions.
- **Project Showcase:** Highlights key projects with tech stacks and GitHub links.
- **Skills Grid:** Interactive skills section using Lucide icons.

## How to View
1. Open `index.html` in any modern web browser.
2. (Optional) To see the Lucide icons correctly, ensure you have an active internet connection as they are loaded via CDN.

## Customization
- **Bio:** Edit the `About` section in `index.html`.
- **Colors:** Modify CSS variables in `:root` and `body.dark-mode` within `style.css`.
- **Projects:** Add or remove project cards in the `#projects` section of `index.html`.

## Built With
- HTML5
- CSS3 (Custom Variables, Flexbox, Grid)
- JavaScript (ES6+, Intersection Observer)
- [Lucide Icons](https://lucide.dev/)
- [Google Fonts (Inter)](https://fonts.google.com/specimen/Inter)
